Materi Singkat

Apa itu Object?

Object adalah cara JavaScript menyimpan banyak data yang saling berkaitan dalam satu variabel. Daripada menulis nama, kelas, dan umur sebagai variabel terpisah, kita merangkainya menjadi satu object dengan pasangan properti: nilai.

1. Membuat Object

Tulis pasangan namaProperti: nilai di dalam kurung kurawal { }, dipisahkan koma:

const siswa = {
  nama: "Nadia",
  kelas: "XI RPL 1",
  umur: 16
};

2. Mengakses Properti

Ada dua cara, hasilnya sama:

  • Dot notation — siswa.nama → "Nadia"
  • Bracket notation — siswa["nama"] → "Nadia"

Ingat: di dalam bracket, nama properti adalah string, jadi harus pakai tanda kutip. siswa[nama] tanpa kutip akan error karena dianggap variabel bernama nama.

3. Mengubah, Menambah & Menghapus

siswa.umur = 17;              // ubah nilai properti
siswa.hobi = "Membaca";       // tambah properti baru
delete siswa.kelas;           // hapus properti

4. Menelusuri Object dengan for...in

Gunakan for...in untuk menampilkan semua properti tanpa menulisnya satu per satu:

for (let kunci in siswa) {
  console.log(kunci + ": " + siswa[kunci]);
}
// nama: Nadia
// umur: 17
// hobi: Membaca

Perhatikan: variabel perulangan (kunci) berisi nama properti sebagai string, jadi untuk mengambil nilainya gunakan bracket: siswa[kunci].

5. Nested Object

Nilai sebuah properti bisa berupa object lagi. Aksesnya bertingkat:

const peserta = {
  nama: "Elang",
  alamat: {
    jalan: "Jl. Kenanga No. 8",
    kota: "Bandung"
  }
};
console.log(peserta.alamat.kota); // "Bandung"

6. Method & this

Properti yang berisi function disebut method. Di dalam method, kata kunci this merujuk ke object pemiliknya:

const kalkulator = {
  nilai: [80, 90],
  rataRata() {
    let total = 0;
    for (let n of this.nilai) total += n;
    return total / this.nilai.length;
  }
};
console.log(kalkulator.rataRata()); // 85

7. Menggabungkan Object (Spread)

Spread operator ... menyalin seluruh isi object ke object baru:

const a = { nama: "Raka" };
const b = { kelas: "XII RPL 1" };
const profil = { ...a, ...b };
// { nama: "Raka", kelas: "XII RPL 1" }
